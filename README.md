# Android SQLite Database Manager

A lightweight Android SQLite learning project based on Java.

This project demonstrates how to use SQLite database operations in Android applications, including database creation, table management, CRUD operations, and practical database learning examples.

## Project Story

This project was originally created several years ago when I started learning Android development.

At that time, my goal was simple: help more Android beginners understand how SQLite works, including database creation, table design, data insertion, query operations, updates, and deletion.

The project was shared as a technical learning article and received attention from many developers. After several years, this project is being redesigned and upgraded into a more complete SQLite learning platform with improved UI, bilingual support, and more practical examples.

The goal is to make Android database learning easier and more accessible for everyone.

## Features

- SQLite database initialization
- Create and manage tables
- Insert data
- Query data
- Update records
- Delete records
- Java based Android implementation
- Beginner friendly examples
- English and Chinese support
- Database learning examples
