# Android SQLite Database Manager

A lightweight Android SQLite learning project based on Java.

This project demonstrates how to use SQLite database operations in Android applications, including database creation, table management, and CRUD operations.

## Features

- SQLite database initialization
- Create and manage tables
- Insert data
- Query data
- Update records
- Delete records
- Simple Android Java implementation
- Easy to understand for beginners

## Project Structure

```
app/
 ├── database/
 │   ├── SQLiteOpenHelper
 │   └── Database operations
 ├── model/
 └── ui/
```

## Requirements

- Android Studio
- Java 8+
- Android SDK

## Usage

1. Clone this repository.
2. Open the project with Android Studio.
3. Build and run on an Android device or emulator.

## Language Support

The project will support:

- English
- 中文

## About SQLite

SQLite is a lightweight embedded relational database. It is widely used in mobile applications because it requires no separate database server and stores data locally.
